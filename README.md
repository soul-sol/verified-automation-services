## How an engagement works

1. Open the matching request form without attaching secrets or private data.
2. Receive a written scope, exclusions, price, and acceptance cases.
3. Provide only the minimum sanitized input needed for the agreed scope.
4. Receive the artifact, validation commands, and known limitations.

No work starts and no payment is requested until both sides have a written
scope. Public issues must never contain credentials, customer data, private
source code, financial records, or proprietary workbooks.

See [delivery and privacy rules](DELIVERY.md).
